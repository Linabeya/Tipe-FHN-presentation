# TIPE — Cycles limites et boucles de propagation dans la dynamique électrique du cœur

Beamer presentation for a TIPE (Travaux d'Initiative Personnelle Encadrés) on the electrical dynamics of the heart, built around the FitzHugh–Nagumo (FHN) model.

## About

This repository contains the LaTeX sources, figures, and Python scripts for a presentation on limit cycles and propagation loops in cardiac electrical dynamics. The talk moves from the biological motivation (spiral waves and cardiac arrhythmias) through the mathematical analysis of the FHN system, an electronic circuit implementation, and numerical simulation of the diffusive FHN model, ending with an interpretation in the context of cardiac defibrillation.

## Presentation outline

1. **Introduction et motivation** — cardiac spiral waves
2. **Contexte biologique et naissance du modèle FHN** — polarization, ion channels, action potential, Hodgkin–Huxley model
3. **Analyse mathématique du système FHN** — nullclines, fixed points, linearization, stable node / stable focus / limit cycle cases
4. **Modèle électronique** — circuit realization (op-amps, resistors, capacitors)
5. **Simulation numérique du modèle diffusif FHN** — 2D grid, periodic boundary conditions, spiral wave formation
6. **Interprétation et exploitation** — application to cardiac defibrillation
7. **Annexe** — Python source code
